# ShopTrack - Smart Inventory & Sales Tracker 🛒📊

ShopTrack is a comprehensive, full-stack web application designed for retail shops, general stores, and small businesses to effortlessly manage their inventory, sales, suppliers, expenses, and track real-time analytics.

## ✨ Features

- **🔐 Secure Authentication:** User login and registration using hashed passwords (`bcryptjs`) and secure sessions (`jsonwebtoken`).
- **📦 Inventory Management:** Add, update, and track products, categories, barcodes, and receive low-stock alerts.
- **💰 Point of Sale (POS) & Billing:** Generate invoices, manage a cart, process checkouts, and automatically calculate profit margins.
- **👥 Customer Management:** Keep track of customer details and their purchase history.
- **🚚 Supplier & Purchase Tracking:** Manage suppliers, track purchase orders, and monitor supplier performance.
- **💸 Expense Tracking:** Log and categorize daily shop expenses.
- **📈 Advanced Reports & Analytics:** 
  - Real-time dashboard with quick stats.
  - Daily sales summaries and revenue overview.
  - Monthly profit and loss calculations.
  - Top-selling product tracking.
- **⚙️ Shop Settings:** Configure shop details, GST/PAN information, and business types.

## 🛠️ Tech Stack

**Frontend:**
- HTML5, CSS3, Vanilla JavaScript
- Fully responsive, custom aesthetic design

**Backend:**
- Node.js & Express.js
- RESTful API Architecture

**Database:**
- MySQL (using `mysql2` promise wrapper)
- **Advanced SQL Features Implemented:** Stored Procedures, Views, Custom Functions, Subqueries, Joins, and Transaction Control Logic (TCL).

## 🚀 Prerequisites

Before you begin, ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (v14 or higher)
- [MySQL Server & MySQL Workbench](https://dev.mysql.com/downloads/)
